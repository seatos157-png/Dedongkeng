him88.frogs — Website Galeri Kodok & Katak
Struktur file lengkap (HTML, CSS, JS terpisah) yang siap di-hosting ke internet agar bisa diakses publik.
Struktur Folder
`index.html` — Halaman utama website
`css/style.css` — Styling responsif & tema gelap
`js/data.js` — Data spesies kodok dan katak
`js/app.js` — Logika pencarian, filter, lightbox, dan tambah foto
Cara Upload ke Internet (Gratis & Cepat)
Netlify Drop (Paling Mudah, Tanpa Coding):
Buka app.netlify.com/drop.
\
Tarik (drag & drop) folder `him88-frogs-web` ke halaman tersebut.
Website langsung online dengan link publik (bisa diganti subdomainnya menjadi `him88-frogs.netlify.app`).
GitHub Pages / Vercel:
Upload seluruh isi folder ini ke repository GitHub, lalu aktifkan GitHub Pages atau hubungkan ke Vercel.
